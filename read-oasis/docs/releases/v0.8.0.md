# Read Oasis v0.8.0 — "Vocabulary Garden"

**Tag:** `v0.8.0-vocabulary-garden`
**Date:** 2026-09-29
**Build stamp:** `sw.js VERSION = ro-2a6c163583b1-085bcc76` · content_hash `2a6c163583b1`
**Status:** Beta — ready for real-child pilot use.

This release moves Read Oasis from "code complete" to **Build → Test → Validate →
Pilot Use**. The headline feature is the **Vocabulary Garden**, a fail-closed,
evidence-driven vocabulary layer built on the Cambridge YLE 2025 word list.

---

## Major additions

- **Vocabulary Garden** — a standalone learning space with child-facing games
  (Listen & Find, Look & Say, Meaning Match, Word Detective, Read-in-Context,
  Position/Action Play).
- **Cambridge YLE 2025 integration** — an immutable, sha256-pinned source lexicon
  of **1403 words** as the corpus foundation. The source layer is never edited by
  hand and never fabricated.
- **Evidence-driven vocabulary progress** — child progress is tracked as evidence
  (localStorage, `STORE_VERSION=2`), designed to move a word through
  Encountered → Recognized → Recalled → Used.
- **Parent vocabulary dashboard** — a PIN-gated parent view with a Vocabulary tab
  showing approved words and progress.
- **Offline support** — service worker precaches the app shell + published books;
  the reader, preview and library work with no network.
- **Playwright end-to-end coverage** — hermetic Chromium E2E for the kid, parent
  and offline flows (no live network).

## Content

- **43 published books** (0 errors at the content publication gate).
- **60 editorially-approved vocabulary entries** (up from 14), each hand-authored
  and sense-verified against a single eligible Cambridge sense:
  - **Batch 1 — book-anchored (14):** words that appear in a real book page and
    auto-map into the reader (`behind`, `cross`, `cycle`, `dry`, `empty`, `heavy`,
    `inside`, `kite`, `midday`, `slow`, `still`, `tail`, `umbrella`, `under`).
  - **Batch 2 — core standalone vocabulary (46 net):** high-frequency, concrete,
    single-sense Pre A1 Starters words for the garden's teaching games — animals,
    body, family, food/drink, everyday objects, colours, contrast adjectives, and
    common actions.
- Remaining corpus is honestly dispositioned: **1213 draft** (awaiting authoring),
  **77 blocked_source_review**, **53 not_teachable_as_standalone**. Nothing is
  fabricated as reviewed.

|---|---|

| Content publication gate | **43 books, 0 errors, 1 warning** |

Fail-closed guarantees enforced by the validator: only approved/published entries
carry teaching content; no quarantined or proper-noun word is ever approved; every
entry and mapping pins the immutable source PDF sha256; manifest counts must match
recomputed counts (rebuild-verified); book-page mappings pin book/revision/page/hash.

## How to run the checks

```powershell
cd read-oasis
# JS unit tests
node --test "test/*.test.mjs"
# Python tests
python -m unittest discover -s test -p "test_*.py"
# Vocabulary validator (must exit 0)
python tools/vocab/validate_vocab.py
# Content publication gate (+ re-stamp sw.js/index on --index)
python tools/validate_content.py --index
# Browser E2E (installs Chromium on first run)
npm install; npx playwright install chromium; npx playwright test
```

## Known limitations

- Audio / listening asset generation is stubbed in tests and not yet verified end
  to end with real audio.
- Cross-browser E2E (Firefox/WebKit) is not yet wired; current E2E runs on
  Chromium only.
- Adaptive recommendation (Evidence → Word Mastery → Book Recommendation →
  Adaptive Path) is deferred until pilot data justifies it.
